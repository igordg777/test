# Dermathey Paris - Дерматологическая клиника

Современный веб-сайт для дерматологической клиники, созданный на основе HTML, CSS и JavaScript.

## 🏥 О проекте

Этот сайт создан для дерматологической клиники Dermathey Paris, вдохновленный современным дизайном и функциональностью. Сайт включает в себя все необходимые разделы для медицинского учреждения.

## ✨ Особенности

- **Адаптивный дизайн** - отлично выглядит на всех устройствах
- **Современный интерфейс** - вдохновлен лучшими практиками веб-дизайна
- **Интерактивность** - плавные анимации и переходы
- **SEO-оптимизация** - семантическая разметка и мета-теги
- **Форма обратной связи** - с валидацией и уведомлениями
- **Мобильное меню** - удобная навигация на мобильных устройствах

## 🚀 Технологии

- **HTML5** - семантическая разметка
- **CSS3** - современные стили с Flexbox и Grid
- **JavaScript (ES6+)** - интерактивность и анимации
- **Font Awesome** - иконки
- **Google Fonts** - типографика

## 📁 Структура проекта

```
clinic/
├── index.html          # Главная страница
├── styles.css          # Стили CSS
├── script.js           # JavaScript функциональность
├── images/             # Папка с изображениями
│   ├── hero-image.svg          # Главное изображение
│   ├── clinic-interior.svg     # Интерьер клиники
│   ├── treatment-room.svg      # Процедурный кабинет
│   ├── skin-treatment.svg      # Лечение кожи
│   ├── medical-equipment.svg  # Медицинское оборудование
│   └── before-after.svg        # Результаты лечения
└── README.md           # Документация
```

## 🎨 Разделы сайта

1. **Главная** - приветствие и основные услуги
2. **Услуги** - подробное описание медицинских услуг
3. **О нас** - информация о клинике и специалистах
4. **Галерея** - фотографии клиники и результатов
5. **Контакты** - форма обратной связи и контактная информация

3. Сайт готов к использованию!

## 🔧 Настройка

### Изменение контента
1. Откройте `index.html`
2. Найдите нужный раздел
3. Измените текст, сохраните файл

### Изменение стилей
1. Откройте `styles.css`
2. Найдите нужный селектор
3. Измените свойства, сохраните файл

### Добавление изображений
1. Поместите изображения в папку `images/`
2. Замените SVG файлы на реальные изображения (JPG, PNG)
3. Обновите пути к файлам в HTML
4. Рекомендуемые размеры:
   - Hero изображение: 400x400px
   - О нас изображение: 400x300px
   - Галерея: 400x300px
